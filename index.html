起飛前下載一次，
整段航程離線聊天。

離線智能助手從你的 VM 下載 Gemma 4 模型包，在 iPhone 上以 LiteRT-LM + Metal GPU 本機執行。聊天不經伺服器，對話只存在你的裝置上。

了解運作方式 私隱承諾

使用流程

  1. 1 首次啟動，從 VM HTTPS 下載 .litertlm 模型包
  2. 2 本機載入 LiteRT 引擎（GPU），準備離線推理
  3. 3 選擇模式，AI 主動開場，全程無需網路

五種離線對話模式

每種模式有獨立 system prompt，進入後 AI 會依模式主動開場，無需先問「想要什麼」。

✨

解悶模式

連登式互動文字 RPG：有名字主角、短節連載、A–D 選項。懸疑／搞笑／荒謬皆可。

🛫

旅遊模式

降落前清單、實用短語與抵達準備，像貼心旅伴。

📝

高效模式

飛行途中專注框架、寫作與計畫整理。

🌙

反思模式

溫和日記引導與自我反思，語氣平靜不評判。

💋

甜故模式 · 18+

互動甜故文字 RPG：有名字主角（非讀者）、短節連載、鹹濕露骨、A–D 選項。

文字 RPG 怎麼玩？

解悶與甜故模式均為連登互動故風格：每節開頭「故事連載中.....」，第三人稱主角，結尾 A–D 選項。

短節連載

每回合 120–220 字，選項驅動劇情，可連續玩落去。

低溫度執筆

故事模式用較低 temperature，劇情較連貫，選項清晰。

架構一覽

VM 只負責託管模型檔；推理與對話記錄都在 iPhone 上完成。

VM（模型託管）

透過 HTTPS 提供 Gemma 4 E2B .litertlm 下載。不接收聊天內容，不做伺服器端推理。

iPhone（邊緣推理）

LiteRT-LM 載入已下載模型，Metal GPU 串流生成回覆。對話 JSON 僅存於 Application Support。

裝置與私隱

建議 6GB+ RAM

Gemma 4 E2B 模型較大，請在實機測試。模擬器可編譯，但 GPU 推理需實機驗證。

對話不上傳

下載完成後，聊天內容不會傳送至 VM 或第三方 AI API。

可刪除模型包

設定頁可刪除或重新下載離線模型，清除各模式對話記錄。
